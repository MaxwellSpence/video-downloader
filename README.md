# OmniDownloader 🚀

Aplicação web completa para download de vídeos e áudios do **YouTube**, **TikTok**, **Instagram**, **Twitter/X**, **Facebook** e mais, direto no computador.

## ✨ Recursos

- 🔗 **Apenas com o Link**: Cole a URL de qualquer vídeo público.
- 🎬 **Vídeo MP4 com Múltiplas Resoluções**:
  - 4K UHD (2160p)
  - 2K QHD (1440p)
  - Full HD (1080p)
  - HD (720p)
  - SD (480p, 360p)
  - Melhor resolução original disponível
- 🎵 **Áudio MP3**:
  - Extração de áudio de alta fidelidade em **320 kbps**.
  - Mantém metadados de artista e título.
- ⚡ **Processamento Local & Seguro**:
  - Utiliza `yt-dlp` integrado com `FFmpeg` e `Deno` para burlar throttles e desafios sem depender de APIs externas pagas ou com anúncios.
- 💻 **Interface Moderna (Dark Mode)**:
  - Design premium estilo glassmorphism.
  - Barra de progresso em tempo real com velocidade (MB/s) e tempo restante (ETA).
  - Histórico de downloads recentes no navegador.
  - Gatilho automático de download para a pasta Downloads do seu computador.

## 🚀 Como Iniciar

Basta dar dois cliques no arquivo:
```
iniciar_site.bat
```
Ou rodar no terminal dentro da pasta:
```bash
python app.py
```
E acessar no navegador: `http://localhost:5000`
